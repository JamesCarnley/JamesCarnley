# James Carnley

**Your friendly neighborhood cypherpunk.**

I'm a systems engineer and Ethereum builder in Chicago. I spent more than a decade at Epic working on critical software, and I've spent years running validators and testing Ethereum clients.

I care about privacy, public goods, and an internet that belongs to the people using it. I like software you can inspect, run yourself, and keep using after its creators move on.

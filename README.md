# James Carnley

**Your friendly neighborhood cypherpunk.**

I'm a systems engineer and Ethereum builder in Chicago. I spent more than a decade at Epic working on critical software, and I've spent years running validators and testing Ethereum clients.

I care about privacy, public goods, and an internet that belongs to the people using it. I like software you can inspect, run yourself, and keep using after its creators move on.

## `~/workshop/`

### `├──` [efs/](https://efs.eth.limo/)

> **Ethereum File System**
>
> The World Computer needs a way to organize its information. I'm building EFS as an open-source public good for organizing and using onchain data, with shared namespaces and views shaped by the sources you choose to trust.
>
> The bigger goal: applications that can share information without sharing a gatekeeper, and people who can change tools without leaving their data behind.
>
